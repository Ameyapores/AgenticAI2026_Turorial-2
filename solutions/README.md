# Reference solutions

This folder contains the generated benchmark results for participant reference.

- `benchmark_results.png` and `learning_convergence.png` are the benchmark figures.
- `benchmark_summary.csv` and `learning_progress.csv` provide the tabular results.
- `benchmark_results.json` records the protocol, scores, and seeds.

Run `python run_benchmark.py` from the repository root to regenerate these files without API calls.
